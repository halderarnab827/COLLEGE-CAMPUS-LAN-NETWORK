# COLLEGE-CAMPUS-LAN-NETWORK
Cisco Packet Tracer-based College Campus LAN network featuring DHCP, OSPF, routing, switching, and connectivity testing across multiple departments.

## Project Overview

This project simulates a college campus network consisting of Management, Office, and Teaching Faculty departments. Each department is connected through routers and switches, while a central server provides network services. The network uses DHCP for automatic IP allocation and OSPF for dynamic routing between departments.

## Components Used

- 3 Routers
- 3 Switches
- 18 PCs
- 1 Main Server
- DHCP
- OSPF
